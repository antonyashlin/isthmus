# Isthmus Meridian — studio foundations

The token system and deck building blocks for **Isthmus Meridian**, measured
from the master deck (16:9, Helvetica Neue). This is the review surface for the
brand system before slides are assembled.

- **Colours** — grounds, text hierarchy, and accents sampled from the deck.
- **Typography** — the Helvetica Neue scale; emphasis is accent-blue, not italic.
- **Spacing** — the deck rhythm on the 1280×720 authoring canvas.
- **Deck System** — logo lockups, eyebrow, cards, and the callout block.

Grounds run deepest to nearest: `#000` stage → `#06121d` background →
`#0b1926` panel → `#0e1e2d` surface. The primary accent `#88c1ed` carries every
emphasis phrase; `#4f83b0` draws the hairline borders and wireframe.
