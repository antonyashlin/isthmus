AND Capital / Icon System

One grid. Every line meets at AND.

The grid. Every icon is drawn on the same three by three node grid, so the whole set reads as one system.

The join. Straight lines only, one 1.25 weight, square terminals. Nodes a line touches are solid; the rest stay as faint points.

The conjunction. Each icon carries one emerald node: the point the idea resolves to. It is the signature of the set, and the only colour.
