AND Capital / Icon System

Cut from the wordmark.

The source. Every icon is built only from what the AND wordmark is made of. Nothing is borrowed from a stock set or another system.

The strokes. Straight stems with flat, square-cut ends, like the letters. Diagonals run only at the A's leg angle. Curves are only the D's bowl, a true semicircle.

The counter. Each icon holds the A's counter, the triangle inside the A, drawn at the same angle in emerald. One per icon, and the only colour.

Stem2.2 at 24px in a 24 unit box. Flat, square-cut ends and mitred joins, like the letters.

CurveEvery curve is the D's bowl: a true semicircle. No freehand curves, no rounded corners.
